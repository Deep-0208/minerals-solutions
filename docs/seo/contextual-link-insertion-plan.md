## 8. Implementation Guardrails

1. **Maintain Link Density Discipline:** Target **3 to 6 contextual inline links** per long-form spoke page (excluding breadcrumbs, cards, and CTAs). Do not turn every mention of a term into a link — link the **first** contextually relevant occurrence per destination per page.
2. **Preserve Exact Canonical Trailing Slashes:** Every inserted `<Link href="...">` MUST include the trailing slash (`/`) matching `trailingSlash: true` in `next.config.ts` to prevent 301 hops.
3. **Keep JSON-LD Clean:** Never embed HTML/JSX inside `FAQPage` JSON-LD `acceptedAnswer.text` strings; render rich JSX via a separate `answerNode` prop in `FaqAccordion.tsx`.
4. **Standardize `?product=` Slugs:** When linking RFQ anchors or updating CTAs, use exact route slugs (`bucket-elevators`, `screw-conveyors`, `belt-conveyors`, `forged-trunnion-rollers`, etc.) once `RequestQuoteClient.tsx` reads `useSearchParams()`.
